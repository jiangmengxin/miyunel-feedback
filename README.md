# Miyunel 读者反馈

[Miyunel](https://miyunel.com) 是一个中文 AI 资讯站：每天一期 AI 日报，条条附原始信源，另有大模型能力榜单。

这个仓库只用来收**读者反馈**，没有网站源码。网站上每条新闻、每个模型页都有「纠错」链接，点进来会自动填好页面和条目：

- [新闻纠错](../../issues/new?template=news-fix.yml)：事实、数字、日期、翻译有误
- [补充 / 更正信源](../../issues/new?template=source.yml)：链接失效，或有更权威的原始来源
- [榜单：分数 / 价格有误](../../issues/new?template=leaderboard.yml)：原始分、官方价格、漏掉的评测
- [提议收录新模型](../../issues/new?template=new-model.yml)

请尽量附上原始来源。核对后我们会更正页面，并在 Issue 里回复。
